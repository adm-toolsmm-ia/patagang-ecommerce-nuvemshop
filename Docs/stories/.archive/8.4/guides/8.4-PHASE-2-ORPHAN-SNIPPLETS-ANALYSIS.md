## ⚠️ **Step 4: Risk Classification**

### Risk Levels for Orphan Removal

#### 🟢 **GREEN (Safe to remove)**
- Old backup files (*.bak)
- Clearly replaced versions (e.g., old product-card vs v3)
- Experimental snipplets (named with -test, -draft, -old)
- Size: ~10-20 files

#### 🟡 **YELLOW (Caution required)**
- Snipplets with ambiguous names (no clear purpose)
- Snipplets that might be loaded dynamically
- Snipplets with complex Liquid logic
- Size: ~50-80 files

#### 🔴 **RED (Do NOT remove)**
- Core payment/checkout snipplets
- Contact form components
- Newsletter/email snipplets
- Custom Patagang-specific snipplets
- Size: ~10-30 files
