## 📝 Dev Notes

### Fase 1: Investigação Profunda (v1.5.69)

**Problema Identificado:**
- HTML do cupom existia em `cart-drawer-new.tpl` (v1.5.69)
- CSS do cupom existia em `style-critical.tpl` (v1.5.69)
- **FALTAVA:** JavaScript para aplicar cupom (cart-drawer.js não tinha handler)

**Impacto:**
- Form fazia POST direto (page reload) em vez de usar Nuvemshop LS API
- UX ruim: sacola fechava e página recarregava

### Fase 3: Correção de UX — Botão WhatsApp (v1.5.73)

**Problema:**
- Botão "Compre pelo WhatsApp" lado esquerdo estava de cabeça para baixo
- Texto não legível quando usuário virava a cabeça para a esquerda

**Causa Raiz:**
- `style-whatsapp-button.css.tpl` tinha `transform: scaleX(-1) rotateZ(180deg)`
- Isso invertia completamente o texto

**Solução:**
- Removido transform invertido
- Texto agora lido naturalmente de cima para baixo (vertical-rl)

**Resultado:**
- ✅ Botão com texto legível do lado esquerdo
- ✅ Design espelhado corretamente do botão direito

## 🎓 Learnings & Patterns

### Pattern: Nuvemshop LS API Integration

```javascript
// Primary: Use LS API if available (no reload)
if (typeof LS !== 'undefined' && LS.addCoupon) {
    LS.addCoupon(code, callback);
}

// Fallback: POST fetch (graceful degradation)
fetch(formAction, {
    method: 'POST',
    body: new FormData(form),
    headers: {'X-Requested-With': 'XMLHttpRequest'}
});
```

**Why:** Nuvemshop provides LS global object with helper methods. Must check availability gracefully.

### Pattern: Text Orientation (Writing Mode)

```css
/* Vertical text reading naturally */
writing-mode: vertical-rl;        /* Top to bottom, right to left */
text-orientation: mixed;           /* Mixed glyphs */

/* DON'T INVERT with transform */
/* ❌ transform: scaleX(-1) rotateZ(180deg); */
/* ✅ Just use writing-mode, it handles orientation */
```
