## 🔍 Seções a Refatorar (PHASE C.2)

### 1. Inputs & Form Fields
**Seletores afetados:**
- `.form-control`, `.form-input`
- `input[type="text"]`, `input[type="email"]`
- `input[type="number"]`, `input[type="password"]`
- `textarea`

**Problemas identificados:**
- `border: 1px solid !important`
- `background-color: #fff !important`
- `padding: 10px !important`
- `font-size: 14px !important`

**Técnica de refactoring:**
```scss
/* ANTES */
input.form-control {
  background-color: #fff !important;
  border: 1px solid #ddd !important;
}

/* DEPOIS (cascata) */
.form-group input.form-control {
  background-color: #fff;     /* Remove !important */
  border: 1px solid #ddd;
}

/* Aumentar especificidade se necessário */
form .form-group input.form-control {
  /* Agora tem especificidade: form > .form-group > input.form-control */
}
```

---

### 2. Form Labels & Text
**Seletores:**
- `label`, `.form-label`
- `.form-text`, `.help-text`

**Problemas:**
- `color: #666 !important`
- `font-size: 12px !important`
- `font-weight: 600 !important`

**Técnica:**
- Usar parent container como contexto
- `.form-group label` em vez de `label !important`

---

### 3. Buttons em Forms
**Seletores:**
- `.btn`, `.btn-primary`, `.btn-default`
- `button[type="submit"]`

**Problemas:**
- `background-color: #007bff !important`
- `padding: 10px 20px !important`
- `color: #fff !important`

**Técnica:**
- Form-level scoping: `.form-actions .btn`
- Semantic HTML: `form button[type="submit"]`

---

### 4. Form States
**Seletores:**
- `:hover`, `:focus`, `:active`
- `.is-valid`, `.is-invalid`
- `[disabled]`

**Problemas:**
- `border-color: #007bff !important`
- `box-shadow: 0 0 0 3px rgba(...) !important`
- `cursor: not-allowed !important`
