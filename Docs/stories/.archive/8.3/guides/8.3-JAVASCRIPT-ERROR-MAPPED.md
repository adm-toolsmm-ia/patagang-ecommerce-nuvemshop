## Notes for Next Developer

1. Error occurs in Nuvemshop's bundled script (not our custom code)
2. Likely a timing issue: code assumes variable exists but it's still null
3. Check if there's an initialization order issue in main.js or store.js.tpl
4. Possible fix: Add null check before calling `.toString()`

Example fix pattern:
```javascript
// Before (crashes if variable is null)
const result = variable.toString();

// After (safer)
const result = variable ? variable.toString() : '';
```
