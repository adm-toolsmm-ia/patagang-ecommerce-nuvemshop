## 🎯 Objetivo

Corrigir **problema crítico de UX**: ao clicar em foto de produto, modal/galeria abre **embaixo da tela** em vez de **fullscreen em frente**.

**Root Cause:** Header com `position: fixed !important` + `z-index: 1000` bloqueando Fancybox lightbox (z-index: 1050).

---

## 🔍 Problema Identificado

**Sintoma:** Clique em foto → Galeria abre parcialmente embaixo, não em fullscreen.

**Causa CSS (Linhas 1899-1905 de style-async.scss.tpl):**
```scss
/* Header fixed com !important demais */
background: transparent !important;
height: var(--header-height) !important;
position: fixed !important;        ← PROBLEMA
top: 0 !important;
left: 0 !important;
width: 100% !important;
z-index: 1000 !important;         ← Menor que fancybox (1050), mas !important cria stacking context
```

**Impacto:**
- Fancybox container (z-index: 1050) não consegue sobrepor
- Modal aparece de forma bugada (embaixo/clipped)
- UX quebrada no mobile/desktop

---

## 🔧 Solução Estratégica

### Abordagem: Remover `!important` de positioning do Header

**Antes (Bugado):**
```scss
position: fixed !important;
z-index: 1000 !important;
```

**Depois (Corrigido via Cascata):**
```scss
/* Aumentar especificidade sem !important */
header.pg-header {
  position: fixed;      /* Remove !important */
  z-index: 999;         /* Abaixo de modal (1050) */
}

/* Fancybox com z-index maior, sem !important needed */
.fancybox__container {
  z-index: 1050;        /* Já existe no CSS minified */
  position: fixed;
}
```

### Técnica de Refactoring

1. **Remover !important de header position rules** (linhas 1899-1905)
2. **Aumentar especificidade com seletor em cascata:** `body .pg-header` → `.page-container .pg-header`
3. **Garantir Fancybox overlay:** `body.with-fancybox { overflow: hidden }` ← Já existe
4. **Testar modal:** Click em foto → Fullscreen overlay, sem clipping
