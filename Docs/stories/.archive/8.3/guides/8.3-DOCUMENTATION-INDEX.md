## 🎓 Methodology Notes

### Refactoring Pattern Used
```css
/* BEFORE: Force specificity with !important */
.selector {
    property: value !important;
}

/* AFTER: Increase selector specificity via cascata */
#parent .selector {  /* More specific = no !important needed */
    property: value;
}
```

**Key Insight:** Always prefer CSS specificity cascata over `!important`. The "waterfall" of CSS rules (cascata in Portuguese) means more specific selectors naturally override less specific ones.
