## 🚨 SE ALGO DER ERRADO

### Problema: Drawer NÃO abre ao clicar ícone
**Solução:**
- [ ] Verificar console: há erro "Cannot read property..."?
- [ ] data-toggle no header está correto? (deve ser `#pg-cart-drawer`)
- [ ] cart-drawer.js está sendo carregado? (console mostra "[PG Cart Drawer]...")
- [ ] LS API disponível? (console mostra "LS API disponível"?)

**Se erro "LS não disponível":**
- cart-drawer.js não consegue acessar LS API Nuvemshop
- Verificar se template Nuvemshop injeta LS corretamente

### Problema: Cupom não funciona
**Solução:**
- [ ] Seção cupom visível?
- [ ] Botão "Aplicar" clicável?
- [ ] Input tem class `.pg-drawer__coupon-input`?
- [ ] Botão tem class `.pg-drawer__coupon-btn`?
- [ ] Console mostra erro na função `applyCoupon()`?

**Se cupom sempre retorna erro:**
- Pode ser que cupom NÃO exista em sua loja
- Tente com cupom GANGDAPATA (padrão Patagang)
- Se não funciona mesmo assim, verificar LS.addCoupon() no console

### Problema: Frete não mostra opções
**Solução:**
- [ ] Loja tem shipping configurado? (store.has_shipping = true)
- [ ] Calculadora inline presente?
- [ ] CEP inserido é válido?
- [ ] Console mostra erro em shipping-calculator?
