## 🎯 PROBLEMAS ESPECÍFICOS + SOLUÇÕES

### Problema 1: Sem Scroll Explícito na Galeria Desktop

**Situação Atual:**
```css
.pg-gallery-container {
  /* Nenhum max-height, nenhum overflow: auto */
  /* Se 10+ imagens, galeria fica MUITO longa */
}
```

**Impacto:**
- Produtos com 10+ imagens criam galeria vertical enorme
- Usuário precisa scroll mucho para chegar até card

**Solução Recomendada:**
```css
.pg-gallery-container {
  max-height: 600px;  /* Fixo ou responsivo (70vh) */
  overflow-y: auto;
  padding-right: 12px;  /* Espaço para barra scroll */
}
```

---

### Problema 2: Alinhamento Vertical Imagem vs Card

**Situação Atual:**
```css
.pg-pdp-image-col {
  align-self: flex-start;  /* No topo */
}

.pg-pdp-info-col {
  align-self: center;      /* No centro vertical */
}
```

**Impacto:**
- Se imagem tem altura 400px e card tem altura 500px → card fica pendurado no ar
- Se imagem tem altura 800px e card tem altura 300px → vazio visual grande no topo do card

**Solução Recomendada:**
```css
/* Opção A: Ambos no topo (imagem e card aligned) */
.pg-pdp-image-col, .pg-pdp-info-col {
  align-self: flex-start;
}

/* Opção B: Ambos centralizados */
.pg-pdp-image-col, .pg-pdp-info-col {
  align-self: center;
}

/* Opção C: Imagem no topo, card com padding-top para alinhar */
.pg-pdp-image-col {
  align-self: flex-start;
}

.pg-pdp-info-col {
  padding-top: 40px;  /* Desloca card para baixo */
  align-self: flex-start;
}
```

---

### Problema 3: Sem Fallback para Backdrop-Filter

**Situação Atual:**
```css
.pg-pdp-info-card {
  background: rgba(255, 255, 255, 0.55);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
}
```

**Impacto:**
- Firefox Desktop (e navegadores antigos) não suportam `backdrop-filter`
- Renderiza como background semi-transparente (OK, mas não tão bonito)
- Pode parecer "desfocado" sem o blur

**Solução Recomendada:**
```css
.pg-pdp-info-card {
  background: rgba(255, 255, 255, 0.85);  /* Fallback: mais opaco */

  @supports (backdrop-filter: blur(1px)) {
    background: rgba(255, 255, 255, 0.55);
    backdrop-filter: blur(12px);
    -webkit-backdrop-filter: blur(12px);
  }
}
```

---

### Problema 4: Barra de Scroll Não Alinhada ao Card

**Situação Atual:**
- Galeria desktop: grid vertical com scroll implícito no container
- Card: ao lado (não alinhado com scroll)
- Resultado: scroll da galeria fica "solto", não parece alinhado ao card

**Impacto:**
- Visualmente confuso em produtos com muitas imagens
- Usuário vê scroll da galeria e não entende que está scrollando galeria

**Solução Recomendada:**
```css
/* Alinhar scroll com card — usar wrapper */
.pg-pdp-image-col {
  max-height: 600px;
  overflow-y: auto;
  padding-right: 12px;
  /* Barra scroll alinhada à direita da coluna */
  align-self: flex-start;
}

.pg-pdp-info-col {
  align-self: flex-start;
  margin-left: 0;  /* Sem margem, direto conectado */
}
```

## 📋 CHECKLIST DE REFATORAÇÃO

### Refatoração Nível 1: CSS Apenas (Sem HTML Changes)

**Recomendado para: Ajustes rápidos**

```css
/* 1. Adicionar scroll na galeria desktop */
.pg-gallery-container {
  max-height: 70vh;
  overflow-y: auto;
  padding-right: 12px;
}

/* 2. Fallback para backdrop-filter */
@supports (backdrop-filter: blur(1px)) {
  .pg-pdp-info-card {
    background: rgba(255, 255, 255, 0.55);
    backdrop-filter: blur(12px);
  }
}

@supports not (backdrop-filter: blur(1px)) {
  .pg-pdp-info-card {
    background: rgba(255, 255, 255, 0.85);
  }
}

/* 3. Alinhar ambas colunas no topo */
.pg-pdp-image-col,
.pg-pdp-info-col {
  align-self: flex-start;
}
```

**Tempo:** ~15 min
**Risco:** Muito baixo
**Impacto:** Alto (melhor UX)

---

### Refatoração Nível 2: HTML + CSS (Estrutural)

**Recomendado para: Melhor controle de layout**

**Mudanças:**
1. Adicionar wrapper `.pg-gallery-wrapper` com max-height
2. Adicionar `sticky` positioning ao card (fica visível ao scroll)
3. Ajustar grid galeria para thumbnail sidebar (desktop)

**Código:**
```html
<!-- NOVO: Wrapper com scroll -->
<div class="pg-pdp-gallery-wrapper">
  <div class="pg-gallery-container">
    <!-- Galeria grid vertical com scroll -->
  </div>
</div>

<!-- NOVO: Sticky card que fica visível ao scroll -->
<div class="pg-pdp-info-col-wrapper">
  <div class="pg-pdp-info-card-sticky">
    <!-- Card com position: sticky -->
  </div>
</div>
```

**Tempo:** ~45 min
**Risco:** Médio (testing necessário)
**Impacto:** Muito Alto (UX profissional)

---

### Refatoração Nível 3: Design System (Full Redesign)

**Recomendado para: Futuro (Story 8.3+)**

Redesenhar:
- Galeria com thumbnails na lateral (não grid vertical)
- Card "sticky" ao scroll (fica no viewport)
- Responsividade aprimorada (tablet 768-991px com layout intermediário)
- Lightbox modal ao clicar na imagem (zoom completo)

**Tempo:** ~2-3 horas
**Risco:** Alto (grandes mudanças)
**Impacto:** Muito Alto (professional e-commerce)
