### CULPADO #3: Falta de CSS para `.section-advertising` quando `.has-ad-bar` está presente

**Arquivo:** `style-colors.scss.tpl:1050-1055`

```scss

  background-color: $main-foreground;
  color: $main-background;
```

**O que acontece:** O CSS está comentado (bom!), mas **não há nenhum CSS substituto** que garanta `.section-advertising` fica transparente quando `.has-ad-bar` está presente!

**Resultado:** `.section-advertising` fica **sem styling definido** e **herda background de elemento PAI**.

**Status:** ✅ IDENTIFICADO

### CULPADO #4: Estrutura HTML — Falta de isolamento real das seções

**Arquivo:** `layouts/layout.tpl:353-377`

```html
<body>
  {% snipplet "header/header-advertising.tpl" %}  <!-- section-advertising -->
  {% snipplet "header/header-patagang.tpl" %}     <!-- header pg-header -->
  {% template_content %}                          <!-- conteúdo página -->
</body>
```

**Problema estrutural:**
- Não há `<section>`, `<div class="wrapper">`, ou container que **isole fisicamente** a advertising do header
- Ambos estão **diretos no body** sem separação
- Se body ou um elemento intermediário tiver background, **ambos herdam**

**Solução estrutural:** Cada bloco deveria estar em seu próprio `<section>` ou container com reset CSS explícito

**Status:** ✅ IDENTIFICADO

### CULPADO #5: CSS cascata de elementos PAI não explicitamente resetados

**Descoberta:**Múltiplas classes em `style-colors.scss.tpl` aplicam `rgba($main-foreground, X)` como background em elementos que podem ser PAIS de `.section-advertising` e `.pg-header`:

```scss
/* Linha 228 */
.placeholder-container { background-color:rgba($main-foreground, 0.1); }

/* Linha 246 */
.placeholder-fade { background-color:rgba($main-foreground, 0.2); }

/* Linha 509 */
.chip { background: rgba($main-foreground,0.1); }
```

**Risco:** Se `.section-advertising` ou `.pg-header` estão dentro de um elemento com essas classes, **herdam o background cinza**.

**Status:** ✅ INVESTIGADO

## 🚀 SOLUÇÃO PROPOSTA (Estrutural)

### Opção A: CSS Agressivo (Quick Fix)
```css
/* Reset ABSOLUTO em layout.tpl */
body .section-advertising,
body .section-advertising * {
    background-color: transparent !important;
    background-image: none !important;
    color: inherit !important;
}

body .pg-header,
body .pg-header * {
    background-color: transparent !important;
    background-image: none !important;
    color: inherit !important;
}

/* Para mobile: garantir styling explícito */
@media (max-width: 768px) {
    body .section-advertising {
        display: block !important;
        margin: 0 !important;
        padding: 10px 20px !important;
        border-bottom: 1px solid rgba(0,0,0,0.05) !important;
    }

    body.has-ad-bar .pg-header {
        display: block !important;
        min-height: 56px !important;
        padding-top: 8px !important;
        margin-top: 0 !important;
    }
}
```

### Opção B: Refatoração Estrutural (Proper Solution)
```html
<!-- layout.tpl -->
<body>
    <!-- SEÇÃO 1: ADVERTISING (isolada) -->
    <section class="section-top" role="banner">
        {% snipplet "header/header-advertising.tpl" %}
    </section>

    <!-- SEÇÃO 2: HEADER (isolada) -->
    <section class="section-header" role="navigation">
        {% snipplet "header/header-patagang.tpl" %}
    </section>

    <!-- SEÇÃO 3: CONTEÚDO (isolado) -->
    <main class="section-content">
        {% template_content %}
    </main>
</body>
```

Com CSS:
```css
.section-top {
    background-color: transparent;
    width: 100%;
    box-sizing: border-box;
}

.section-header {
    background-color: var(--header-bg, transparent);
    width: 100%;
    box-sizing: border-box;
}

.section-content {
    background-color: var(--content-bg, #ffffff);
    width: 100%;
    box-sizing: border-box;
}
```
