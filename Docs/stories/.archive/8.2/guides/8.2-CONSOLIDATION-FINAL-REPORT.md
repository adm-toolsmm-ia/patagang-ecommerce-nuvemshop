## Lessons Learned

1. **Layout Issues:** `display: flex` without `flex-direction` causes unexpected column layouts
2. **Banner Positioning:** DOM structure (where component is included) affects z-index/positioning
3. **Incremental Deployment:** Quick validation per version prevents cascading issues
4. **CSS Modernization:** Aspect-ratio + data-attributes cleaner than padding-bottom hack
