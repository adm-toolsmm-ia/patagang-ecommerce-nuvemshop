## ✅ **Tarefa 3: Adicionar Comentários "PORQUE CRÍTICO"**

### **Para cada seção, adicionar bloco explicativo:**

```css
/* ============================================
   HEADER & NAVIGATION
   Navigation bar, logo, search
   ============================================ */

/* CRITICAL REASON: Header é fixed (position: sticky)
   e apareça no topo de TODAS as páginas above-the-fold.
   Sem estilos críticos = FOUC (flash) = UX ruim.
   Reduzir tamanho aqui impactaria conversão significativamente.
*/
```

### **Exemplos de "PORQUE CRÍTICO":**

```
✓ HERO:
  "Visível imediatamente no page load (LCP metric).
   Usuários veem antes de qualquer interação.
   Sem CSS = layout shift detectado."

✓ PRODUCT PAGE:
  "Gallery modal é acionado por clique do usuário,
   mas CSS deve estar pronto imediatamente.
   Modal abrir = user ja está engajado, não pode falhar."

✓ CART:
  "Modal cart é acionado por clique (add to cart button).
   CSS crítico garante resposta imediata (< 500ms).
   Requer display, position, z-index inline."

✗ FILTERS (moved in v1.5.116):
  "Filters/sort não são above-the-fold.
   Acionados por user action (click).
   CSS pode carregar assincronamente com segurança."
```

## ✅ **Tarefa 4: Remover Versioning Antigo**

### **Buscar e remover linhas como:**

```css
/* PATAGANG v1.5.33: PRODUCT GALLERY MODAL & NAV BUTTONS */
/* PATAGANG v1.5.36: MODERN & MINIMALIST UX/UI — Gallery Images */
/* PATAGANG v1.5.63: MOBILE GALLERY FIX */
/* PATAGANG v1.6.0 — FASE 2 MODERNIZATION CSS */
```

### **Razão:**
- Comentários de versão desatualizados confundem
- Git history + commits já rastreiam mudanças
- Melhor deixar apenas "CURRENT" sem história

### **Substituir por:**

```css
/* PATAGANG — Product Gallery Modal & Navigation
   Last updated: Story 8.2 ETAPA 2 (v1.5.116)
   Note: Gallery Modal CSS moved to style-async (non-critical)
*/
```
