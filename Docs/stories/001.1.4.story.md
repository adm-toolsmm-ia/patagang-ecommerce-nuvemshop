### 3. User Story (Clear Intent)

```
As a blind or visually impaired user using a screen reader,
I want meaningful alternative text for all product images,
So that I understand what products are shown without seeing them.

ACCEPTANCE CONTEXT:
- Current State: Product images missing alt text
- Target State: All images have descriptive, meaningful alt text
- Standard: WCAG 2.1 (1.1.1 Text Alternatives)
- Coverage: Product pages, category pages, homepage hero images
- Quality: Alt text describes image content, not generic ("image")
```

### 4. Acceptance Criteria (Testable Checklist)

**AC-1: Alt Text Coverage**
```
□ All <img> tags on homepage have alt attribute
□ All product page images have alt text
□ All category page images have alt text
□ No alt="" (empty) attributes remaining
□ Dynamic images generated with alt text
□ Background images: <img> instead of CSS background (where applicable)
□ Alt text is not redundant with surrounding text
```

**AC-2: Alt Text Quality**
```
□ Alt text describes image content (not "image" or "photo")
□ Example: "Blue cotton t-shirt with logo" (not "product image")
□ Alt text under 125 characters (readable by screen readers)
□ Decorative images: alt="" (intentionally empty)
□ Linked images: include context (e.g., "Buy now: Blue t-shirt")
□ Product images: include product name and key attributes
```

**AC-3: Screen Reader Testing**
```
□ NVDA (Windows): Read all alt text, makes sense
□ JAWS (Windows): Read all alt text, complete information
□ VoiceOver (macOS): Read all alt text clearly
□ iOS VoiceOver: Product images read with context
□ Android TalkBack: Product images understood
□ No repetition (alt text + button text)
```

**AC-4: Dynamic Content & Forms**
```
□ User-uploaded images: alt text required before upload
□ Product variants: alt text reflects variant (size, color)
□ Checkout images: CTA images have context (e.g., "Continue shopping")
□ Form icons: Accessibility labels added if icons only
□ Carousel: Alt text accurate for current slide
```

**AC-5: Code Quality & Consistency**
```
□ No console warnings for missing alt attributes
□ Linting passes (if alt-text linting enabled)
□ No missing <img> src attributes
□ <picture> elements have <img> with alt inside
□ SVG images: <title> or aria-label when needed
□ Inline SVG: aria-label or description added
```

**AC-6: WCAG 2.1 (1.1.1) Compliance**
```
□ Axe DevTools audit: 0 violations for "images"
□ All images have text alternative
□ Decorative images: alt="" with no aria-label
□ No alt text duplication (not same as caption)
□ Alt text purpose clear (describes content, not function)
□ Works with browser zoom (alt text visible if image fails)
```

**AC-7: Performance & No Regressions**
```
□ Page load time: No variance from baseline
□ Image loading: Unchanged
□ No broken links or missing images
□ Existing CSS unchanged
□ No JavaScript errors introduced
□ Product catalog: All 50+ products have alt text
```

**AC-8: Documentation & Knowledge**
```
□ Alt text guidelines documented (team wiki)
□ Examples provided (good vs. bad alt text)
□ New team members can apply guidelines independently
□ Documentation: Linked in README
□ Code comments: Explain alt text intent where complex
```
