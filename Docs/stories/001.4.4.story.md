### 4. Acceptance Criteria (Testable Checklist)

**AC-1: Jest Testing Framework Training**
```
□ Workshop 1: Jest basics (1 hour)
  □ Introduction to Jest
  □ Writing first test
  □ Running tests locally (npm run test)
  □ Test organization and naming
  □ Hands-on: Team writes 1 test each
□ Workshop 2: Advanced Jest (1.5 hours)
  □ Mocking and spying
  □ Async tests (promises, setTimeout)
  □ Coverage reports
  □ Debugging tests
  □ Hands-on: Debug failing test together
□ Outcome: Team confident writing unit tests
□ Verification: Team writes tests independently
```

**AC-2: Cypress E2E Testing Training**
```
□ Workshop 3: Cypress basics (1.5 hours)
  □ Introduction to Cypress
  □ Setting up first test
  □ Selectors and best practices
  □ Running tests (npm run cypress:run)
  □ Hands-on: Team writes 1 E2E test
□ Workshop 4: Advanced Cypress (1.5 hours)
  □ Page Object Model (POM)
  □ Waiting and async handling
  □ Debugging failing tests
  □ CI integration
  □ Hands-on: Extend existing tests
□ Outcome: Team confident writing E2E tests
□ Verification: Team creates tests independently
```

**AC-3: CI/CD Pipeline Training**
```
□ Workshop 5: GitHub Actions (1 hour)
  □ How CI/CD works
  □ Workflows (lint, test, build)
  □ PR status checks
  □ Fixing CI failures
  □ Hands-on: Trigger workflows, check status
□ Workshop 6: Deployment Process (1 hour)
  □ FTP deployment (Nuvemshop)
  □ Cache busting (Story 1.2)
  □ Version management
  □ Rollback procedures
  □ Hands-on: Simulate deployment to staging
□ Outcome: Team confident with CI/CD processes
□ Verification: Team understands workflow
```

**AC-4: Code Quality & Standards Training**
```
□ Workshop 7: Commit & PR Standards (45 min)
  □ Conventional Commits format
  □ Branch naming conventions
  □ PR descriptions and checklists
  □ Code review expectations
  □ Hands-on: Create PR with proper format
□ Workshop 8: Accessibility Standards (45 min)
  □ WCAG AA compliance (from Phase 1)
  □ Alt text, labels, focus indicators
  □ Testing with screen readers
  □ Tools (Axe, NVDA/JAWS)
  □ Hands-on: Audit page for accessibility
□ Outcome: Team follows standards consistently
□ Verification: All commits follow conventions
```

**AC-5: Design System & Components Training**
```
□ Workshop 9: Design System (1 hour)
  □ Design tokens and CSS variables
  □ Component library overview
  □ When to create new components
  □ Design system usage in development
  □ Hands-on: Use design system in new component
□ Workshop 10: Storybook (1 hour)
  □ Storybook as component documentation
  □ Creating and managing stories
  □ Interactive prop adjustment
  □ Accessibility checks in Storybook
  □ Hands-on: Create new component story
□ Outcome: Team comfortable with design system
□ Verification: All new components documented
```
