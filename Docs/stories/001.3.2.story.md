### 4. Acceptance Criteria (Testable Checklist)

**AC-1: LCP (Largest Contentful Paint) Optimization**
```
□ Target: < 2.5 seconds
□ Image optimization: WebP from Story 3.1
□ Lazy loading: Implement for below-fold images
□ CSS/JS: Critical path optimized
□ Font loading: async or swap strategy
□ Server response: < 600ms
□ Verified: Lighthouse audit shows LCP < 2.5s
```

**AC-2: FCP (First Contentful Paint) Optimization**
```
□ Target: < 1.5 seconds
□ CSS: Critical CSS inlined (above-fold)
□ JS: Defer non-critical scripts
□ Fonts: System fonts or pre-loaded
□ Images: No render-blocking images
□ Network: Minimize network requests
□ Verified: Lighthouse audit shows FCP < 1.5s
```

**AC-3: CLS (Cumulative Layout Shift) Elimination**
```
□ Target: < 0.1 (good)
□ Images: Width/height attributes set
□ Fonts: font-display: swap
□ Animations: transform/opacity only (no layout changes)
□ Ads/embeds: Reserved space or aspect-ratio
□ Dynamic content: No layout reflows
□ Verified: Lighthouse CLS < 0.1
```

**AC-4: JavaScript Optimization**
```
□ Code splitting: Split by route/feature
□ Lazy loading: Load code on demand
□ Tree-shaking: Remove unused code
□ Minification: Production builds minified
□ Source maps: For debugging
□ Bundle size: Target < 100KB JS (gzipped)
□ Verified: No render-blocking JS
```

**AC-5: CSS Optimization**
```
□ Critical CSS: Inlined for above-fold
□ Non-critical: Deferred loading
□ Minification: CSS minified
□ Unused CSS: Removed
□ Media queries: Separated if needed
□ Bundle size: Target < 50KB CSS (gzipped)
□ Verified: No render-blocking CSS (except critical)
```

**AC-6: Network Optimization**
```
□ Compression: gzip/brotli enabled
□ CDN: Leverage CDN for static assets (if available)
□ Caching: Browser cache headers set
□ HTTP/2: Server supports multiplexing
□ DNS: Pre-fetch critical domains
□ Preload: Critical resources pre-loaded
□ Verified: Network tab shows < 3s load time
```
