### 3. User Story (Clear Intent)

```
As a performance engineer,
I want product images converted to WebP format with PNG/JPG fallbacks,
So that page load time decreases and data consumption reduces
while maintaining backward compatibility.

ACCEPTANCE CONTEXT:
- Current State: All images in PNG/JPG format (~2MB homepage)
- Target State: WebP primary + PNG/JPG fallback (~1MB reduction)
- Goal: 50%+ image size reduction
- Compatibility: 95%+ browsers support WebP
- Method: <picture> element with <source> srcset
- Safety: 100% backward compatible (fallback images)
```
