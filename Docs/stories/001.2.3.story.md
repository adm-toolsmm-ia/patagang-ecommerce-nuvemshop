### 3. User Story (Clear Intent)

```
As a developer,
I want a build pipeline configured for CSS/JS bundling,
So that code can be optimized, tree-shaken, and deployed
with minimal bundle size and maximum performance.

ACCEPTANCE CONTEXT:
- Current State: No formal build process
- Target State: Webpack 5+ with CSS/JS bundling
- Optimization: Tree-shaking unused code
- Output: Optimized assets for Nuvemshop FTP
- Cache busting: Integrated with version system (Story 1.2)
```

### 4. Acceptance Criteria (Testable Checklist)

**AC-1: Webpack Installation & Configuration**
```
□ Webpack 5+ installed (npm install --save-dev webpack webpack-cli)
□ webpack.config.js created with entry/output configuration
□ Mode: production (minified output) and development (source maps)
□ CSS loader: Extract CSS to separate files
□ JS loader: Babel for ES6+ transpilation
□ Asset loader: Images, fonts, SVG optimization
□ Build script: npm run build (production) and npm run dev (development)
```

**AC-2: CSS Bundling**
```
□ CSS files bundled into single or multiple files
□ CSS minimized (remove whitespace, comments)
□ Source maps generated (for debugging in dev)
□ CSS variables preserved (from Story 1.5)
□ Media queries grouped (optimization)
□ Vendor prefixes added (autoprefixer)
```

**AC-3: JavaScript Bundling**
```
□ JavaScript bundled from entry points
□ ES6+ code transpiled to ES5 (Babel)
□ Unused code tree-shaken (webpack mode: production)
□ Code split for large applications (if needed)
□ Source maps for debugging
□ Minification enabled (terser)
```

**AC-4: Asset Optimization**
```
□ Images: Optimized (lossy/lossless compression)
□ WebP conversion: Generate modern format
□ Fallbacks: Original formats for older browsers
□ SVG: Inline or sprite sheet (configurable)
□ Fonts: Self-hosted, subset loaded (if used)
□ Hash-based filenames: Cache busting (content hash)
```

**AC-5: Build Performance**
```
□ Build time: < 30 seconds (full build)
□ Development build: < 5 seconds (fast rebuild)
□ Watch mode: < 2 seconds (fast recompile)
□ Output size: CSS+JS < 200KB (gzipped)
□ Memory usage: < 500MB during build
□ No build warnings or errors
```

**AC-6: Integration with Deployment**
```
□ Build output: FTP-ready assets in dist/
□ Version parameter: Integrated with Story 1.2 cache busting
□ Theme structure: Assets placed in correct Nuvemshop paths
□ HTML generated: Links to built assets with versions
□ Ready for CI/CD: Build artifact deployable
```

**AC-7: Development Experience**
```
□ npm run dev: Development server with hot reload
□ npm run build: Production build
□ npm run serve: Test production build locally
□ npm run analyze: Bundle size analysis tool
□ npm run clean: Clear build artifacts
□ Source maps: Debugging in DevTools
```

**AC-8: Code Quality & Documentation**
```
□ webpack.config.js documented with comments
□ Build process documented in README
□ Troubleshooting guide created
□ CI/CD ready (build artifact reproducible)
□ No console warnings
□ Code review approved by 2+ team members
```
