## 📋 User Story

**Como** visitante da Patagang na página de produto
**Quero** que o botão "Compre pelo WhatsApp" (esquerda) tenha a mesma identidade visual do botão "Posso ajudar?" (direita), mas com o texto em direção oposta
**Para** que os dois botões laterais pareçam simétricos e intencionais — como um par espelhado

---

## 🎯 Acceptance Criteria

- [ ] **AC 1:** Botão "Compre pelo WhatsApp" (lado esquerdo): texto lê de baixo para cima
- [ ] **AC 2:** Botão "Posso ajudar?" (lado direito): texto lê de cima para baixo (sem alteração)
- [ ] **AC 3:** Visual dos dois botões aparece espelhado / simétrico horizontalmente
- [ ] **AC 4:** Dimensões, cores, padding e fonte do botão WhatsApp permanecem idênticos ao estado atual
- [ ] **AC 5:** Ícone WhatsApp (SVG) não é afetado pela mudança de direção do texto
- [ ] **AC 6:** Comportamento no mobile (fixed, centralizado verticalmente) permanece correto
- [ ] **AC 7:** Link do WhatsApp continua funcional

---

## 🔍 Root Cause (Diagnóstico Confirmado)

**Estado atual:** Ambos os botões usam `writing-mode: vertical-rl` com `text-orientation: mixed`.

- `style-help-sidebar.css.tpl` (linhas 32-33):
  `.pg-help-btn__text { writing-mode: vertical-rl; text-orientation: mixed; }` → lê de cima para baixo

- `layout.tpl` (linha 516, inline style):
  `body .btn-whatsapp-left span { writing-mode: vertical-rl !important; text-orientation: mixed !important; }` → **mesma direção**

**Fix:** Adicionar `transform: rotate(180deg) !important` ao `.btn-whatsapp-left span` no bloco inline de `layout.tpl`.
- `writing-mode: vertical-rl` com `rotate(180deg)` inverte a direção de leitura (de baixo para cima)
- O botão "Posso ajudar?" continua sem alteração

---

## 🔧 Escopo Técnico

### IN (o que será feito)
Adicionar `transform: rotate(180deg) !important` à regra existente `.btn-whatsapp-left span` no bloco `<style>` inline de `layout.tpl`:

```css
/* ANTES: */
body .btn-whatsapp-left span {
    writing-mode: vertical-rl !important;
    text-orientation: mixed !important;
    font-size: 12px !important;
    ...
}

/* DEPOIS: */
body .btn-whatsapp-left span {
    writing-mode: vertical-rl !important;
    text-orientation: mixed !important;
    transform: rotate(180deg) !important; /* Direção oposta ao "Posso ajudar?" (lê de baixo p/ cima) */
    font-size: 12px !important;
    ...
}
```

### OUT (o que NÃO será feito)
- Não alterar `style-help-sidebar.css.tpl` (botão "Posso ajudar?" não muda)
- Não alterar `snipplets/whatsapp-left.tpl` (HTML do botão)
- Não alterar posicionamento, cores ou dimensões do botão

- [ ] `transform: rotate(180deg)` em elemento `inline` (span) — não afeta `position: fixed` do pai
