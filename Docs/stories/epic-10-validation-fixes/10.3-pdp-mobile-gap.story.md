## 📋 User Story

**Como** visitante da Patagang no mobile
**Quero** que a página de produto (PDP) não tenha um espaço em branco excessivo entre o header e o conteúdo
**Para** que o conteúdo do produto seja visível imediatamente sem precisar rolar a tela

---

## 🎯 Acceptance Criteria

- [ ] **AC 1:** No mobile (≤576px), o espaço entre o header fixo e o banner informativo é de ~130px (não ~260px)
- [ ] **AC 2:** O banner informativo (descontos/informações) é visível sem scroll no mobile
- [ ] **AC 3:** No desktop (≥577px), o espaçamento do PDP permanece inalterado
- [ ] **AC 4:** Em outras páginas (home, categoria, blog), o banner informativo não é afetado
- [ ] **AC 5:** O header fixo não sobrepõe o conteúdo após a correção
- [ ] **AC 6:** Em tablet (577px-768px), o layout permanece correto

---

## 🔍 Root Cause (Diagnóstico Confirmado)

**Causa raiz:** Duplo espaçamento de 130px + 130px = 260px no mobile PDP.

```
style-critical.tpl linha 3654:
  @media (max-width: 576px) {
    main.patagang-section-content { padding-top: 130px; }  ← offset do header fixo
  }

style-critical.tpl linha 2047:
  div.product-informative-banner { margin-top: 130px; }  ← SEM media query, aplica em todos os breakpoints
```

**Estrutura DOM no PDP:**
```html
<main class="patagang-section-content">  <!-- padding-top: 130px no mobile -->
  <div id="single-product">
    <div class="product-informative-banner">  <!-- margin-top: 130px (REDUNDANTE no mobile) -->
    ...
```

**Nota:** O `margin-top: 130px` no banner existe para compensar o header fixo no desktop. No mobile, o `main` já faz isso via `padding-top: 130px`. Logo, o banner precisa de `margin-top: 0` no mobile em páginas de produto.

---

## 🔧 Escopo Técnico

### IN (o que será feito)
Adicionar 1 regra CSS em `style-critical.tpl` na seção do `.product-informative-banner`:

```css
/* PATAGANG vX.X.X: Mobile PDP — remove duplicate header-offset margin
   main.patagang-section-content já aplica padding-top: 130px no mobile (linha 3654)
   O banner não precisa do margin-top adicional em páginas de produto */
@media (max-width: 576px) {
  body.template-product div.product-informative-banner {
    margin-top: 0;
  }
}
```

**Localização:** Após a linha 2055 (`body:not(.template-product) div.product-informative-banner { margin-top: 0; }`), agrupando as overrides do banner juntas.

### OUT (o que NÃO será feito)
- Não alterar `padding-top` do `main` (usada por todas as páginas no mobile)
- Não alterar `margin-top: 130px` original (usado no desktop para offset do header)
- Não alterar outras páginas além do PDP mobile
