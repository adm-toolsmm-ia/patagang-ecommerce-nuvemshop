## 🔍 Root Cause (Diagnóstico Confirmado)

**Causa raiz:** `snipplets/header/header-patagang.tpl` linha 29 usa `style="display: none;"` inline no elemento `.js-dropdown-content`. O JavaScript só adiciona/remove a classe `.is-open`, mas o inline style tem maior especificidade que a regra CSS `.pg-header__dropdown.is-open { display: block; }` em `style-menu-patagang.css.tpl`.

**Resultado:** O dropdown nunca aparece porque o inline style vence.

---

## 🔧 Escopo Técnico

### IN (o que será feito)
- Remover `style="display: none;"` do HTML do dropdown em `header-patagang.tpl` (linha 29)
- Adicionar `display: none;` ao CSS base do seletor `.pg-header__dropdown` em `style-menu-patagang.css.tpl`
- O JS permanece inalterado — apenas gerencia as classes `.is-active` e `.is-open`

### OUT (o que NÃO será feito)
- Não alterar o JS do dropdown
- Não alterar o layout do header
- Não alterar o menu mobile
- Não usar `!important` nessa correção

### Arquivos Impactados
| Arquivo | Mudança | Linhas |
|---------|---------|--------|
| `snipplets/header/header-patagang.tpl` | Remover atributo `style="display: none;"` | Linha 29 |
| `static/css/style-menu-patagang.css.tpl` | Adicionar `display: none;` ao `.pg-header__dropdown` base | Linha ~322 |
