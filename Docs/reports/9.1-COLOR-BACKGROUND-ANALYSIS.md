# Story 9.1 — Análise Completa de Colors/Backgrounds

**Status:** Investigation - Background CSS Hierarchy Analysis
**Date:** 2026-03-26
**Finding:** Banner não responde a CSS direto porque a variável global `$main-background` sobrescreve tudo

---

## 📊 MAPEAMENTO DE HIERARQUIA CSS

### NÍVEL 1: GLOBAL (style-colors.scss.tpl)

```scss
/* LINHA 77: Variável GLOBAL definida por settings da loja */
$main-background: {{ settings.background_color }};  /* = BRANCO (#FFFFFF) */

/* LINHA 213: Aplicada ao BODY (pai de tudo) */
body {
  background-color: $main-background;  /* = BRANCO */
}
```

**Implicação:** Qualquer elemento que NÃO tem `background-color` explícito herda branco do body.

## 🚨 PROBLEMA IDENTIFICADO

**Por que o amarelo (#FFFF00) não apareceu:**

1. **layout.tpl linha 505:** `main.patagang-section-content { background-color: #ffffff; }`
   - Tem MAIOR especificidade que `.pg-pdp-banner-warning`
   - O main cobre TUDO dentro dele com branco

2. **Hierarquia de especificidade:**
   ```
   main.patagang-section-content (especificidade: 2) ← VENCE
   .pg-pdp-banner-warning (especificidade: 1)
   ```

3. **Herança em cascata:**
   ```
   body (branco)
   └── section.patagang-section-top (transparent !important, mas...)
       └── .pg-pdp-banner-warning (amarelo, mas...)
           └── SOBRESCRITO por main.patagang-section-content (branco #ffffff)
   ```

## 🎯 RECOMENDAÇÕES DE QUALIDADE

### 1. CENTRALIZAR DEFINIÇÕES DE BACKGROUND

**Proposta:**
```
Criar uma "lista branca" de elementos que podem ter background colors:
- body: background-color (definido pela loja via settings)
- main, section, div: background-color (componentes específicos)
- Tudo o mais: transparent ou inherit
```

### 2. REMOVER REDUNDÂNCIAS

**Auditoria recomendada:**
```
- Procurar `background-color: #ffffff` → Reduzir a 1-2 locais (body + main)
- Procurar `background-color: transparent !important` → Usar simples `transparent`
- Procurar `background-color` com `!important` → Remover flags desnecessários
```

### 3. DOCUMENTAR CAMADAS CSS

```
CAMADA 1: Global (style-colors.scss.tpl)
  - body: background-color = settings
  - Variáveis: $main-background, $main-foreground, etc

CAMADA 2: Components (style-critical.tpl)
  - Componentes específicos: main, header, sections
  - Devem SEMPRE ter background color explícito

CAMADA 3: Async (style-async.scss.tpl)
  - Estilos não-críticos
  - Não devem conflitar com Camada 2
```
