# Archive – Documentos obsoletos ou históricos

Documentos que **não são mais a fonte da verdade** atual, mas são mantidos para rastreabilidade.

---

## Quando colocar aqui

- Versões antigas de documentos que foram consolidados em outra pasta.
- Auditorias ou relatórios pontuais que não precisam estar na pasta da feature.
- Qualquer doc que não deva ser usado como referência principal.

---

## Estado atual

Esta pasta está vazia. O histórico por feature está em `features/<nome>/archive/` (ex.: Search Overlay).
