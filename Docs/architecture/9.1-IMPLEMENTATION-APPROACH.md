## 🎯 Implementation Strategy

### Phase 1: CSS Changes (15 minutes)

**File:** `theme-deploy-corrigido/static/css/style-critical.tpl`

**Current State (Lines 3579-3608):**
```css
main.patagang-section-content {
    padding-top: 160px;  /* Space for fixed header (~120px) + ad bar (~40px) = ~160px */
}

body.template-product main.patagang-section-content {
    padding-top: 0;  /* ✅ Banners estão dentro, eles controlam seu espaçamento */
}

@media (max-width: 991px) {
    main.patagang-section-content {
        padding-top: 140px;  /* Tablet: slightly less */
    }

    body.template-product main.patagang-section-content {
        padding-top: 0;  /* ✅ Banners controlam espaçamento */
    }
}

@media (max-width: 576px) {
    main.patagang-section-content {
        padding-top: 130px;  /* Mobile: header is smaller but still fixed */
    }

    body.template-product main.patagang-section-content {
        padding-top: 0;  /* ✅ Banners controlam espaçamento */
    }
}
```

**Proposed Change:**
```css
/* DESKTOP: Generic pages get header space only (100px) */
body:not(.template-product) main.patagang-section-content {
    padding-top: 100px;  /* ✅ Only header space (120px - 20px buffer) */
}

/* DESKTOP: Product pages keep existing pattern */
main.patagang-section-content {
    padding-top: 160px;  /* Default for pages without template class */
}

body.template-product main.patagang-section-content {
    padding-top: 0;  /* ✅ Banners estão dentro, eles controlam seu espaçamento */
}

/* TABLET: Adjust for generic pages */
@media (max-width: 991px) {
    body:not(.template-product) main.patagang-section-content {
        padding-top: 90px;  /* Tablet adjustment */
    }

    main.patagang-section-content {
        padding-top: 140px;  /* Default, may be overridden */
    }

    body.template-product main.patagang-section-content {
        padding-top: 0;  /* ✅ Banners controlam espaçamento */
    }
}

/* MOBILE: Adjust for generic pages */
@media (max-width: 576px) {
    body:not(.template-product) main.patagang-section-content {
        padding-top: 80px;  /* Mobile adjustment */
    }

    main.patagang-section-content {
        padding-top: 130px;  /* Default, may be overridden */
    }

    body.template-product main.patagang-section-content {
        padding-top: 0;  /* ✅ Banners controlam espaçamento */
    }
}
```

**Rationale:**
- Generic pages: `padding-top: 100px` = header space only (~120px) minus 20px buffer
- Product pages: `padding-top: 0` = unchanged (banners control)
- Media queries: Proportional reduction (tablet: -10px, mobile: -20px)
- Uses `:not()` selector for clean CSS (CSS4, supported in modern browsers + Nuvemshop environment)

## 🔧 Implementation Details

### CSS Selector Strategy
**Why `:not(.template-product)` instead of individual selectors?**
- More maintainable (single source of truth for generic pages)
- Cleaner CSS cascade
- Follows DRY principle
- Modern browsers fully support `:not()` in CSS3+

### Media Query Order
- Desktop first (defaults) → Media queries override
- Tablet: 991px breakpoint (Bootstrap standard)
- Mobile: 576px breakpoint (Bootstrap standard)
- Matches existing breakpoints in codebase

### Padding-Top Values Rationale
| Device | Current | New | Reason |
|--------|---------|-----|--------|
| Desktop | 160px | 100px | Header (120px) - buffer (20px) |
| Tablet | 140px | 90px | Proportional (-50px) |
| Mobile | 130px | 80px | Proportional (-50px) |
| Product All | 0px | 0px | Unchanged |
