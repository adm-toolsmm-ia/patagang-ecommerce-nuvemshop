## 📋 Diagnóstico do Problema

### Erro Encontrado
```
Status HTTP: 500 Internal Server Error
Mensagem: "Problemas com o servidor"
```

### Causa Raiz
**Arquivo:** `snipplets/header/header-search-overlay.tpl`
**Linha:** 48

```twig
❌ ERRADO (causou erro 500):
{% set launch_items = products | where('tags', 'lançamento') | take(6) %}
```

**Problema:** O filtro Twig `where()` com a sintaxe `where('field', 'value')` **NÃO é suportado** pelo engine de templates do Nuvemshop.

---

## ✅ Solução Aplicada

### Simplificação do Template
Removido o filtro `where()` que não é válido em Nuvemshop.

**Versão Antiga (com erro):**
```twig
{# Tentar buscar produtos com tag "lançamento" #}
{% set launch_items = products | where('tags', 'lançamento') | take(6) %}
{% if launch_items | length > 0 %}
  {# Mostrar produtos tagueados #}
  {% for product in launch_items %}
    ...
  {% endfor %}
{% else %}
  {# Fallback: mostrar categorias #}
  {% set launch_categories = [...] %}
  ...
{% endif %}
```

**Versão Nova (corrigida):**
```twig
{# Apenas usar categorias customizáveis (sem filtro where()) #}
{% set launch_categories = ['Novidades', 'Em Alta', 'Exclusivos', ...] %}
{% for category in launch_categories %}
  <a href="{{ store.search_url }}?q={{ category | url_encode }}" ...>
    {{ category }}
  </a>
{% endfor %}
```

### Por que essa abordagem é melhor?

1. **Compatibilidade 100%** com Nuvemshop templates
2. **Sem dependências de filtros complexos**
3. **Melhor UX** - Categorias fixas são mais previsíveis que tags dinâmicas
4. **SEO friendly** - Cada categoria é uma busca rastreável
5. **Simplicidade** - Sem lógica complexa no template
