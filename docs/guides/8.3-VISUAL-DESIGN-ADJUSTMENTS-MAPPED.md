## Issue #1: Mobile Product Gallery — Duplicate Components

### Problem
Na página de produto (PDP) em mobile, estão aparecendo **duas componentes de visualização de imagens**:
1. Grid 2x2 (desktop gallery)
2. Carousel Swiper (mobile carousel — foto única)

### Expected Behavior
- **Desktop (>992px):** Grid vertical com todas imagens
- **Mobile (<768px):** Carousel Swiper (foto única com navegação)
- **Nunca:** Ambas renderizadas simultaneamente

### Files Involved
- `snipplets/product/product-image.tpl` — Template com separação via `d-lg-block` e `d-lg-none`
- `static/css/style-critical.tpl` — Media queries (verificar sobrescrita de display)
- `static/css/style-async.scss.tpl` — Estilos de galeria

### Root Cause Analysis Required
- [ ] CSS media query conflito (display property sobrescrita?)
- [ ] HTML rendering logic issue (ambas classes ativos?)
- [ ] Bootstrap breakpoint mismatch (d-lg vs media queries custom)?

### Recommended Resolution
Manter **Carousel Swiper no mobile** (melhor para conversão):
- UX nativa mobile (padrão Shopify/Amazon)
- Foco na imagem individual
- Menor CLS impact

### Acceptance Criteria
- [ ] Grid 2x2 **oculto** em mobile (<768px)
- [ ] Carousel Swiper **visível** em mobile
- [ ] Desktop gallery **intacta** (>992px)
- [ ] Zero CLS degradation
- [ ] Console sem erros

## Issue #2: Product Informative Banner — White Background

### Problem
Banner de aviso/informação na PDP tem `background: white` mas deveria ser `background: transparent`.

### Location
`snipplets/product/product-informative-banner.tpl` (elemento `.product-informative-banner`)

### Expected Behavior
- Banner com fundo transparente
- Conteúdo visível contra cor de fundo da página
- Alinhado com design minimalista Patagang

### Files Involved
- `snipplets/product/product-informative-banner.tpl` — Template (sem bg inline)
- `static/css/style-*.scss.tpl` — CSS com background branco (localizar)

### Root Cause Analysis Required
- [ ] CSS rule `.product-informative-banner { background: white; }`
- [ ] Nuvemshop default stylesheet
- [ ] Bootstrap `.product-informative-banner` class styling

### Recommended Resolution
```css
.product-informative-banner {
    background: transparent !important;
    /* ou remover background completamente */
}
```

### Acceptance Criteria
- [ ] Banner fundo transparente
- [ ] Conteúdo legível contra fundo
- [ ] Desktop + Mobile visualmente OK
- [ ] Nenhuma regressão visual
