### ✅ 5. Fix LCP Preload Resolution — FIXO
**Arquivo:** `theme-deploy-corrigido/snipplets/preload-images.tpl`
**Linha:** 61 (antes e depois)

**Problema Anterior:**
```html
<!-- Preload para mobile apenas (640w é muito pequeno para desktop) -->
<link rel="preload" as="image"
  href="{{ image | product_image_url('large') }}"
  imagesrcset="
    {{ image | product_image_url('large') }} 480w,
    {{ image | product_image_url('huge') }} 640w,      ← INADEQUADO
    {{ image | product_image_url('original') }} 1024w   ← INADEQUADO
  ">
```

**Solução Aplicada:**
```html
<!-- Preload com resoluções corretas para desktop rendering -->
<link rel="preload" as="image"
  href="{{ image | product_image_url('large') }}"
  imagesrcset="
    {{ image | product_image_url('large') }} 480w,     ← Mobile (OK)
    {{ image | product_image_url('huge') }} 1600w,     ← Desktop (FIXED: 640w → 1600w)
    {{ image | product_image_url('original') }} 2400w  ← Ultra HD (FIXED: 1024w → 2400w)
  ">
```

**Benefício:**
- LCP (Largest Contentful Paint) carrega na resolução correta para desktop
- Menos reflow quando imagem real é carregada em 'huge' resolution
- Core Web Vitals melhoram (menos CLS)

**QA Esperado:**
- Imagem LCP carrega em resolução máxima sem reflow
- DevTools Lighthouse mostra melhor LCP score
- F12 Network: preload size adequado (~160-200KB para huge)
