## 📋 **PARTE 2: Animação Deslizante** (3 minutos)

### Desktop (1920x1080)
```
Mantenha a página aberta e observe por 30-40 segundos
```

- [ ] **MOVIMENTO HORIZONTAL**
  - [ ] Texto COMEÇA no lado ESQUERDO
  - [ ] Texto move para a ESQUERDA continuamente
  - [ ] Texto desaparece no lado ESQUERDO (sai da tela)
  - [ ] Texto volta a aparecer no lado DIREITO
  - [ ] Loop se repete infinitamente (sem parar)

- [ ] **QUALIDADE DA ANIMAÇÃO**
  - [ ] Movimento é SUAVE (não jogo ou pixelado)
  - [ ] Velocidade é CONSISTENTE (não varia ao longo do tempo)
  - [ ] Sem flickering ou piscadas
  - [ ] Sem saltos abruptos entre loops
  - [ ] SEM TRAVAMENTOS durante a animação

- [ ] **TIMING (tempo de ciclo)**
  - [ ] Uma volta completa leva ~30 segundos (contar mentalmente)
  - [ ] Tempo é consistente ao longo de múltiplos ciclos

- [ ] **INTERAÇÃO**
  - [ ] Animação continua ao passar mouse sobre o banner
  - [ ] Clique no banner (se houver link) funciona sem travamento
  - [ ] Animação NÃO PAUSA quando clicado
