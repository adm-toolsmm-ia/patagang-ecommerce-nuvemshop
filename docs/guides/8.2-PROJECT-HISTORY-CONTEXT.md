## 🎯 TIMELINE HISTÓRICO

### v1.0-v1.2 — Desenvolvimento com IA (2025-Q4)

**Contexto:** Galeria criada como prototipo rápido via geração de código com IA

**Decisões:**
- Mobile carousel com Swiper JS (library padrão Nuvemshop)
- Desktop gallery com grid CSS (responsivo)
- Modal para zoom full-screen (overlay escuro)

**Padrões IA (Gerados automaticamente):**
1. **Padding-bottom hack para aspect-ratio**
   ```html
   <a style="padding-bottom: {{ image.height / image.width * 100}}%;">
   ```
   - **Razão IA:** Técnica de 2015, era comum para manter aspect-ratio em imagens
   - **Problema:** Depende de dimensões Twig, sem fallback CSS, não modernizado
   - **Status (v1.5.41):** ⏳ Ainda em produção, necessário refatorar v1.6.0

2. **Lazyload duplo (HTML nativo + Swiper)**
   ```html
   <img loading="lazy" class="lazyload">  <!-- HTML native -->
   <!-- Swiper init: lazy: true -->     <!-- Swiper plugin -->
   ```
   - **Razão IA:** Hedge — usar 2 sistemas para garantir lazy-load funcionasse
   - **Problema:** Conflito, double-fetch em redes lentas, comportamento imprevisível
   - **Status (v1.5.41):** ⏳ Ainda em produção, necessário consolidar v1.6.0

3. **aria-hidden estático (WCAG falha)**
   ```html
   <div id="pg-modal-gallery" aria-hidden="true">
   ```
   - **Razão IA:** Padrão de acessibilidade copiado de exemplo genérico
   - **Problema:** aria-hidden nunca muda ao abrir/fechar modal, screen reader não avisa
   - **Status (v1.5.41):** ⏳ Ainda em produção, necessário dinâmico v1.6.0

4. **SVG sem size-lock CSS**
   ```html
   <svg><!-- sem width/height em CSS --> </svg>
   ```
   - **Razão IA:** Simplificação, assumiu SVGs inline não causariam CLS
   - **Problema:** SVG pode encolher se flexbox contrair, causa Cumulative Layout Shift
   - **Status (v1.5.41):** ⏳ Ainda em produção, necessário size-lock CSS v1.6.0

**Resultado v1.2:**
- ✅ Galeria funcional em desktop/mobile
- ✅ Modal fullscreen abre/fecha
- ✅ Todos os tests passaram
- ⚠️ 4 padrões IA deixados "como estão" (não era prioridade revisar geração)

## 🔴 Critical Discoveries (Padrões IA que Causam Problemas)

### Problem 1: Padding-Bottom Hack (Não é violação, mas obsoleto)

**Onde está:**
```html
<!-- theme-deploy-corrigido/snipplets/product/product-image.tpl:56-59 -->
<a style="padding-bottom: {{ image.dimensions['height'] / image.dimensions['width'] * 100}}%;">
```

**Por que IA fez assim:**
- Em 2015-2018, CSS `aspect-ratio` não existia
- Técnica de padding-bottom era padrão da indústria
- IA copiou pattern comum da época

**Por que é problema agora:**
- CSS `aspect-ratio` existe desde 2020
- Padrão antigo, menos legível, depende de dimensões Twig
- Desktop gallery já usa `aspect-ratio: 1` (inconsistência)
- **NÃO é violação Nuvemshop** (estilos inline OK)

**Solução v1.6.0:**
```html
<!-- Modernizar para -->
<a class="pg-slide-link" style="aspect-ratio: {{ image.dimensions['width'] }} / {{ image.dimensions['height'] }};">
```

---

### Problem 2: Lazyload Duplo (Conflito Real)

**Onde está:**
```html
<!-- product-image.tpl:72 -->
<img loading="lazy" class="lazyload" ...>

<!-- store.js.tpl:1723 -->
createSwiper('.js-swiper-product', {
  lazy: true,  // ← Conflito com HTML native
  ...
});
```

**Por que IA fez assim:**
- 2015: lazysizes.js era único mecanismo confiável
- 2020: HTML native `loading="lazy"` adicionado
- IA gerou hedging strategy (2 sistemas = mais seguro?)
- **Errado:** 2 sistemas competem, não cooperam

**Por que é problema:**
- Swiper tenta lazy-load, HTML nativo tenta lazy-load
- Em redes lentas: double-fetch de mesma imagem
- Em cache: conflitos de cache strategy
- Performance: + requisições desnecessárias

**Solução v1.6.0:**
```javascript
// Remover lazy: true, usar APENAS native loading="lazy"
createSwiper('.js-swiper-product', {
  lazy: false,  // ← Disable Swiper lazy
  // ... resto unchanged
});
```

---

### Problem 3: aria-hidden Estático (WCAG Fail)

**Onde está:**
```html
<!-- product-image.tpl:57 -->
<div id="pg-modal-gallery" aria-hidden="true">
```

**Problema:**
- `aria-hidden="true"` significa "screen reader ignora este elemento SEMPRE"
- Quando modal abre, aria-hidden CONTINUA `true`
- Screen reader não anuncia "modal opened"
- **WCAG 2.1 Fail:** Modal deve ser acessível quando visível

**Por que IA fez assim:**
- Copiou pattern genérico de exemplo HTML
- Não considerou que aria-hidden precisa ser DINÂMICO
- Assumiu `is-open` class era suficiente (não é, aria é diferente)

**Solução v1.6.0:**
```javascript
// Em openModal()
modal.setAttribute('aria-hidden', 'false');

// Em closeModal()
modal.setAttribute('aria-hidden', 'true');
```

---

### Problem 4: SVG Sem Size-Lock (CLS Risk)

**Onde está:**
```html
<!-- product-image.tpl:34-39, 128-143 -->
<svg class="pg-gallery-zoom-icon"><!-- sem width/height em CSS --></svg>
<svg class="pg-modal-nav"><!-- sem width/height em CSS --></svg>
```

**Problema:**
- SVG flexbox item sem `flex-shrink: 0`
- Se parent shrinks, SVG encolhe → reflow
- Cumulative Layout Shift (CLS) score increases
- Lighthouse penaliza performance

**Por que IA fez assim:**
- Assumiu SVG inline sempre mantém size (errado)
- Não considerou flexbox container shrinking

**Solução v1.6.0:**
```scss
.pg-gallery-zoom-icon svg,
.pg-modal-nav svg {
  width: 20px;
  height: 20px;
  flex-shrink: 0;  // ← Lock size
  display: block;  // ← Prevent inline quirks
}
```

## 🎯 LIÇÕES APRENDIDAS (Para Stories 8.3-8.5)

### Lição 1: IA Gera Padrões Legados
**Implicação:** Código IA é 100% funcional mas pode usar técnicas antigas
**Ação:** Considerar modernização incremental (não reescrever)
**Aplicável a:** Story 8.3-8.5 (identificar legacy patterns em novo código)

### Lição 2: Hedge Thinking é Antipattern
**Implicação:** 2 sistemas em 1 coisa = conflito, não redundância
**Ação:** Consolidar para mecanismo único (nativo prefere a terceiros)
**Aplicável a:** Story 8.5 JS (remover jQuery, consolidar listeners)

### Lição 3: Incremental Fixes Preservam Investimento
**Implicação:** Refactora 1 coisa por vez, teste em produção, valida Gabriel
**Ação:** FASE 2 (v1.6.0) refactora 4 problemas em 6 fases, não big rewrite
**Aplicável a:** Todas futuras (padrão humano > padrão IA)

### Lição 4: Padrões Crescem Incrementalmente
**Implicação:** Desktop `aspect-ratio: 1` foi adicionado v1.5.30, mobile ainda padding-bottom
**Ação:** Consistência DEPOIS de refactor (não antes)
**Aplicável a:** Story 8.4 (consolidar padrões em snipplets)

### Lição 5: Living Documentation é Essencial
**Implicação:** Cada versão documentada, decisões explicadas, POR QUÊ claro
**Ação:** Este arquivo EXPLICA histórico, FASE 2 docs explica refactor
**Aplicável a:** Todas futuras (documentar contexto contemporaneamente)
