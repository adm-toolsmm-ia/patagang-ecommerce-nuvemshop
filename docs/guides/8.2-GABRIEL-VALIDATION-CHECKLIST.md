## 🔴 **IF YOU FIND ISSUES**

### Issue: Page loads blank or very slowly
**Action:**
1. Check F12 Console for red errors
2. Reload page (Ctrl+F5 to clear cache)
3. If still blank, tell @dev immediately
4. @dev will roll back: `git revert HEAD`

### Issue: Product images don't load
**Action:**
1. Check F12 Network tab → look for failed image requests
2. Check if Nuvemshop image server is responsive
3. Tell @dev if persistent

### Issue: Contact form doesn't submit
**Action:**
1. Check F12 Console for JavaScript errors
2. Try refreshing page
3. Tell @dev immediately

### Issue: Blog page looks broken
**Action:**
1. This is OK — blog CSS loads async, might take 2-3 seconds
2. Reload page
3. Should appear styled after 2-3 seconds
4. If doesn't appear after 5 seconds, tell @dev
