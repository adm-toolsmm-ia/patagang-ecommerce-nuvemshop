# Story 8.2 ETAPA 2 — Header Ad-Bar Separation Fix

**Versão:** v1.5.28
**Data:** 2026-03-22
**Status:** ✅ Deployed
**Arquivo modificado:** `theme-deploy-corrigido/layouts/layout.tpl`

---

## 📋 Problema

Na página de produto, o banner de aviso (faixa com "Frete grátis...", "10% OFF...") e o header Patagang compartilhavam fundo cinza claro — desejado era que o banner fosse transparente e o header mantivesse sua aparência original sem herdar cor.

### Causa Identificada
- CSS em `header-patagang.tpl` diferenciava `body:not(.has-ad-bar)` em mobile
- Quando `.has-ad-bar` estava presente, faltava CSS para garantir header visualmente independente
- Resultado: header em mobile herdava cor de `section-advertising`

---

## ✅ Solução Implementada

### Arquivo: `theme-deploy-corrigido/layouts/layout.tpl`
**Linhas:** 183-196 (expandido de 184-186)

**O que foi adicionado:**
```css
/* Ensure header stays independent when ad bar present */
@media (max-width: 768px) {
    body.has-ad-bar .pg-header {
        min-height: 56px !important;
        padding-top: 8px !important;
        padding-bottom: 8px !important;
    }
    body.has-ad-bar .pg-header__logo-img {
        max-height: 26px !important;
    }
}
```

**Garantias:**
- ✅ Header background sempre `transparent !important` (quando `.has-ad-bar`)
- ✅ Logo height mantém 26px em mobile
- ✅ Padding ajustado para separação visual clara (8px top/bottom)
- ✅ Min-height garantido para elementos responsive
