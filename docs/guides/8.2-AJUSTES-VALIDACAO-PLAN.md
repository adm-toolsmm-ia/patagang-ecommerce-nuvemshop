**Problema:** Desconfigurado — grid deve ser 2x2 (4 fotos em 2 linhas, 2 colunas)
**Localização:** `snipplets/product/product-image.tpl`
**Estrutura Esperada:**
```
DESKTOP (>= 768px):
  - Grid 2 colunas x 2 linhas (4 fotos visíveis)
  - Scrollbar vertical para fotos adicionais
  - Tamanho card responsivo às margens

MOBILE (< 768px):
  - Carousel SWIPER (atual, funciona bem)
```

**Estratégia:**
- Corrigir CSS da classe `.pg-gallery-grid`
- Implementar `grid-template-columns: 1fr 1fr;` (2 colunas)
- Implementar `grid-template-rows: repeat(2, 1fr);` (2 linhas)
- Adicionar `overflow-y: auto;` com scrollbar estilizada
- Manter `max-height` responsivo
