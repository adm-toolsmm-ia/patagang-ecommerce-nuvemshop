**JS Changes (store.js.tpl lines 1782-1793):**
```javascript
// openModal now toggles aria-hidden
function openModal(index) {
    currentIndex = index;
    updateMainImage();
    modal.classList.add('is-open');
    modal.setAttribute('aria-hidden', 'false');  // Dynamic toggle
    document.body.style.overflow = 'hidden';
}

// closeModal now toggles aria-hidden
function closeModal() {
    modal.classList.remove('is-open');
    modal.setAttribute('aria-hidden', 'true');   // Dynamic toggle
    document.body.style.overflow = '';
}
```

**Impact:**
- Modal aria-hidden now dynamic (toggles with open/close)
- WCAG 2.1 improvements: role="dialog", aria-modal="true", aria-label added
- Screen readers now understand modal state

**Validation:**
- ✅ Modal opens/closes normally
- ✅ aria-hidden attribute updates correctly
- ✅ No console warnings
