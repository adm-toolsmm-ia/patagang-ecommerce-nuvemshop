## 🔧 PHASE 3: TEMPLATE UPDATES (1-2 hours)

### Step 1: Locate CSS Loading in layout.tpl

**Find:**
```liquid
{% if "" == "CriticalCSS" %}
  <!-- Current critical CSS loading -->
  <style>{{ "css/style-critical.tpl" | asset_url | stylesheet_tag }}</style>
{% endif %}
```

**Verification:**
- [ ] Located style-critical.tpl in layout.tpl

---

### Step 2: Add Async CSS Loading

**Add after critical CSS:**
```liquid
<!-- Load non-critical CSS asynchronously -->
<link rel="preload" href="{{ "css/style-async.scss.tpl" | asset_url }}" as="style" onload="this.onload=null;this.rel='stylesheet'">
<noscript>
  <link rel="stylesheet" href="{{ "css/style-async.scss.tpl" | asset_url }}">
</noscript>
```

**Verification:**
- [ ] Preload link syntax correct
- [ ] onload callback present
- [ ] Noscript fallback included
- [ ] No liquid syntax errors

## 📞 Blockers & Escalation

**If you encounter:**

❌ **CSS extraction causes FOUC:**
- Verify async CSS loading syntax
- Check browser console for errors
- May need to move more CSS to critical

❌ **Lighthouse score doesn't improve:**
- Verify CSS file was actually reduced
- Check if other assets are blocking (JS, images)
- May need image optimization (separate story)

❌ **Nuvemshop constraints fail:**
- Verify checkout CSS unchanged
- Verify footer still visible
- Check forms still functional

**Escalation:** If blocked >2 hours, contact Gabriel
