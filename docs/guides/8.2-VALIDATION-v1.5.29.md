## 🚨 IMPORTANTE: Limpeza de Cache

**Seu navegador pode estar mostrando versão antiga (v1.5.28 ou anterior).**

### Passo 1: Limpar Cache Completamente

**Windows/Linux (Chrome, Firefox, Edge):**
```
Ctrl + Shift + Delete
→ Selecionar "Tudo" (All time)
→ Desmarcar "Cookies"
→ Marcar "Imagens em cache" + "Arquivos em cache"
→ Clicar "Limpar dados"
```

**Mac:**
```
Cmd + Shift + Delete  (ou)
Cmd + Option + E (Safari)
```

### Passo 2: Verificar Versão Carregada

1. Abrir: **https://patagang.com.br/**
2. Pressionar: **F12** (ou Cmd+Option+J no Mac)

**Se não vir v1.5.29:**

## ✅ Validação Visual

**URL:** https://patagang.com.br/{qualquer-produto}

### Mobile (até 768px)
Abrir DevTools → Mobile view (iPhone 12 ou similar)

**Verificar:**
- [ ] **Banner de aviso** ("Frete grátis..., "10% OFF..."):
  - **SEM fundo cinza** (completamente transparente)
  - Texto preto visível
  - Borda fina abaixo (linha cinza claro)

- [ ] **Header Patagang** (logo + menu + ícones):
  - **SEM herdar cinza** do banner acima
  - Logo 26px de altura
  - Fundo branco OU seu design original
  - Separação clara do banner (espaço visual)

- [ ] **Banner do Produto** ("3% DO PEDIDO...", "VISTA O PROPÓSITO", etc.):
  - Cor branca ou seu design original
  - **Claramente separado** do header

### Desktop (> 768px)
Remover mobile view → testar normal

**Verificar:**
- [ ] Banner aviso: transparente, sem cascata cinza
- [ ] Header: design original, sem alterações
- [ ] Produto: banner com cor correta
- [ ] Sem FOUC (flash of unstyled content)

## 📋 CSS Aplicado em v1.5.29

```css
/* AGGRESSIVE ISOLATION */
body .section-advertising {
    background-color: transparent !important;
    background-image: none !important;
    color: inherit !important;
    padding: 10px 20px !important;
    box-shadow: none !important;
}

body .pg-header {
    background-color: transparent !important;
    color: inherit !important;
    border: none !important;
    box-shadow: none !important;
}
```

Todas as propriedades de background/image/color têm `!important` para garantir cascade completa.
