### ✅ **Ajuste #2: Banner Background — Light Gray + Flex Layout**

**File:** `static/css/style-critical.tpl` (added ~55 lines)

**Changes:**
```scss
.product-informative-banner {
  background: #F5F5F5;  /* Light gray instead of white */
  flex-direction: column;
  /* ... */
}

/* Mobile: Stack vertically with better spacing */
@media (max-width: 767px) {
  .product-informative-banner .col-md {
    width: 100%;
    padding: 1.25rem;
    border-bottom: 1px solid #EFEFEF;
  }
}

/* Desktop: Items side-by-side */
@media (min-width: 768px) {
  .product-informative-banner {
    flex-direction: row;
  }
  .product-informative-banner .col-md {
    border-right: 1px solid #EFEFEF;
  }
}
```

**Impact:**
- ✅ Banner background changed from white to light gray (#F5F5F5)
- ✅ Better text distribution via flex layout
- ✅ Mobile: Vertical stack with 1.25rem padding
- ✅ Desktop: Horizontal layout with divider lines
- ✅ Improved visual hierarchy and readability

### ✅ **Ajuste #3: Mobile Gallery — Remove Grid 2x2, Show Swiper Only**

**File:** `static/css/style-critical.tpl` (added ~18 lines media query)

**Changes:**
```scss
@media (max-width: 991px) {
  /* Hide grid 2x2 on mobile completely */
  .pg-gallery-container {
    display: none !important;
  }

  /* Ensure Swiper is visible on mobile */
  .product-image-container {
    display: flex !important;
  }

  .js-swiper-product {
    display: block !important;
  }
}
```

**Impact:**
- ✅ **Desktop (≥992px):** Grid 2x2 thumbnail layout visible (unchanged)
- ✅ **Mobile (<992px):** Grid 2x2 hidden completely, Swiper carousel shows ONLY
- ✅ No more duplicate gallery visualization on mobile
- ✅ Cleaner mobile UX with single carousel experience
