### CSS Target Architecture

**Novo Bloco (após .pg-gallery-item):**

```scss
// ===== ASPECT RATIO CONTAINER (Mobile Carousel) =====
.aspect-ratio-container {
  display: block;
  width: 100%;
  position: relative;
  aspect-ratio: auto;  // Fallback

  // CSS aspect-ratio takes priority over padding-bottom
  @supports (aspect-ratio: 1/1) {
    aspect-ratio: attr(data-aspect-ratio, auto);
  }
}

// ===== SVG SIZE LOCK (CLS Prevention) =====
.pg-gallery-zoom-icon svg,
.pg-modal-nav svg,
.pg-modal-close svg {
  display: block;
  flex-shrink: 0;  // Prevent shrinking
  width: var(--icon-size, 20px);
  height: var(--icon-size, 20px);
}
```

**Mudanças:**
1. ✅ Adicionar `.aspect-ratio-container` rule
2. ✅ Adicionar SVG size-lock rules
