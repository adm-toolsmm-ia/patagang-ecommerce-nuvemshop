## 📖 Description

O arquivo `style-critical.tpl` com 205 KB é carregado inline na tag `<head>`, bloqueando a renderização da página até que todo o CSS seja processado. Este é o **maior impacto de performance** do projeto.

**Estratégia:**
1. **Manter inline:** CSS do header, navegação, hero acima da dobra
2. **Mover para async:** CSS de cards, filtros, sidebar, blog, páginas secundárias
3. **Técnica:** CSS será carregado via `<link rel="preload">` com `onload` para não bloquear

**Métrica esperada:**
- LCP: ~4s → < 2s (50% improvement)
- FCP: ~2.5s → < 1s (60% improvement)
- Performance score: ~65 → 85+ (30% improvement)

**Constraint Nuvemshop:**
- ✅ Checkout: Não tocar em `checkout.scss.tpl` (será carregado separadamente)
- ✅ Footer: Manter visível (não ocultar com display:none)
- ✅ Forms: Contact, registration, newsletter INTACTAS

**Technique - Async CSS Loading:**
```liquid
<!-- Inline critical CSS in <head> -->
<style>
  /* Only above-the-fold CSS here (~30-40KB) */
</style>

<!-- Load non-critical async -->
<link rel="preload" href="style-async.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="style-async.css"></noscript>
```

**Files to analyze for above-the-fold CSS:**
- Header/navigation colors, positioning
- Hero section styling
- Button states
- Typography for viewport
- Minimal layout grid
