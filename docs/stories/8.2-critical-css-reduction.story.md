## 📖 Description (AIOX-Aligned — Re-scoped)

O arquivo `style-critical.tpl` com 163.7 KB é carregado inline na tag `<head>`, bloqueando a renderização da página até que todo o CSS seja processado.

**Análise Realista:**
- **Imóvel (~64 KB):** Bootstrap Grid (~30 KB) + Swiper (~14 KB) + Base CSS (~20 KB)
- **Movível (~42 KB):** Gallery Modal CSS (15-18 KB) + Filters/Sort CSS (20-25 KB)
- **Meta Realista:** 163.7 KB → ~122 KB (26% reduction, vs original < 50 KB que era irrealista)

**Estratégia (3 ETAPAS):**
1. **ETAPA 1:** Mover Gallery Modal CSS (linhas 4905-5382) → style-async.scss.tpl
   - Deploy v1.6.0, Gabriel valida (gallery modal funciona), @qa gate
2. **ETAPA 2:** Mover Filters/Sort CSS (linhas 4300-4904) → style-async.scss.tpl
   - Deploy v1.6.1, Gabriel valida (filtros funcionam), @qa gate
3. **ETAPA 3:** Refatorar estrutura e TOC de style-critical.tpl
   - Deploy v1.6.2, @qa gate final, merge to main

**Princípio:** Zero remoção de CSS — apenas reorganização para critical path vs async. Código consolidado, não deletado.

**Métrica Realista:**
- Performance score: ~65 → ~75-80 (11-23% improvement, realista)
- LCP: ~3.5s → ~2.5s (28% improvement)
- CSS critical path: 163.7 KB → 122 KB (26% reduction)

## 🔧 Technical Context

**Arquivos envolvidos:**
- `theme-deploy-corrigido/static/css/style-critical.tpl` — 205 KB (REDUZIR)
- `theme-deploy-corrigido/static/css/style-async.scss.tpl` — 151 KB (EXPANDIR)
- `theme-deploy-corrigido/layouts/layout.tpl` — Modificar para carregar async CSS

**Constraint Nuvemshop:**
- ✅ Checkout: Não tocar em `checkout.scss.tpl` (será carregado separadamente)
- ✅ Footer: Manter visível (não ocultar com display:none)
- ✅ Forms: Contact, registration, newsletter INTACTAS

**Technique - Async CSS Loading:**
```liquid
<!-- Inline critical CSS in <head> -->
<style>
  /* Only above-the-fold CSS here (~30-40KB) */
</style>

<!-- Load non-critical async -->
<link rel="preload" href="style-async.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="style-async.css"></noscript>
```

**Files to analyze for above-the-fold CSS:**
- Header/navigation colors, positioning
- Hero section styling
- Button states
- Typography for viewport
- Minimal layout grid
