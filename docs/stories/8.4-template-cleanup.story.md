## 📖 Description

Durante análise do projeto, encontrados:
1. **`footer.tpl` em root** e **`snipplets/footer/footer.tpl`** — possível duplicação
2. **Arquivos `.tpl.bak`** — residuais de edições antigas
3. **Arquivo `nul`** na raiz — residual de operação Windows (não deve estar em Git)
4. **Snipplets sem uso** — inclusos em layout antigos, não mais usados

**Objetivo:**
- Remover duplicações e residuais
- Documentar estrutura final de snipplets
- Garantir zero quebras após cleanup

---

## 🔧 Technical Context

**Estrutura esperada:**
```
theme-deploy-corrigido/
├── layouts/              # Principais (layout.tpl, product.tpl, etc.)
├── snipplets/            # Componentes (header/, footer/, product-card/, etc.)
│   ├── footer/footer.tpl    (única fonte de footer)
│   ├── header/
│   ├── product-card/
│   └── ... outros
├── static/               # CSS, JS, imagens
└── ...
```

**Possíveis duplicações a investigar:**
- `footer.tpl` (root) vs `snipplets/footer/footer.tpl`
- `*.tpl.bak` files (remnants)
- `nul` file (Windows artifact)
- Snipplets inclusos em layout mas não mais usados

**Constraint Nuvemshop:**
- ✅ Estrutura de templates não pode quebrar
- ✅ Todos os includes devem apontar para snipplets corretos
